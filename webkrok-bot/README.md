# WEBKROK Telegram-бот

Бот-меню для лідогенерації: клієнт обирає послугу кнопками, відповідає на 2
уточнення, бачить приклад кейсу і залишає номер телефону — заявка одразу
летить тобі в Telegram.

## Розгортання на Vercel

Використовуються два боти:
- **WebkrokBot** — клієнтський, з ним спілкується клієнт (меню, кнопки)
- **MYwebkrokBot** — надсилає тобі готові заявки

1. Обидва боти вже створені через @BotFather, токени є.

2. Переконайся, що ти хоч раз написав `/start` боту **MYwebkrokBot** — інакше
   він не зможе написати тобі першим (обмеження Telegram Bot API).

3. Залий цю папку в GitHub-репозиторій і підключи до Vercel (як інші
   проєкти — `tyomka-catalog`, `webkrokkonstruktor`).

4. У налаштуваннях проєкту на Vercel → **Environment Variables** додай:
   - `BOT_TOKEN` — токен WebkrokBot
   - `ADMIN_BOT_TOKEN` — токен MYwebkrokBot
   - `ADMIN_CHAT_ID` — твій особистий Telegram chat_id

5. Після деплою постав вебхук (один раз, з браузера або curl) для
   **WebkrokBot**, підставивши його токен і адресу проєкту:

   ```
   https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<твій-проєкт>.vercel.app/api/webhook
   ```

6. Напиши **WebkrokBot** `/start` — має з'явитись меню, а заявка після
   заповнення прийде тобі через MYwebkrokBot.

## Що можна допрацювати пізніше

- Замінити приклади кейсів (`CASE_EXAMPLES` у `api/webhook.js`) на реальні
  фото/посилання на портфоліо
- Додати посилання на цього бота в шапку профілю Instagram (webkrok)
- Перенести сесії з in-memory Map на постійне сховище (Vercel KV / Neon
  Postgres), якщо з'явиться помітне навантаження і сесії почнуть губитись
  між "холодними" запусками функції
